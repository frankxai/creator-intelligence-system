# Name the traffic source

First-party taxonomy (extracted 2026-08-21): Browse, Channel pages,
End screens, Shorts, Notifications, Playlists, Suggested videos,
YouTube search, External sites, Advertising, and others.

**Agent use:** each Brief in CIP should declare a primary intended
source. Packaging, title, and first 15 seconds change with that source.

Docs change. Re-fetch before treating this list as eternal.
